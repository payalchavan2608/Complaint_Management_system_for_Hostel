Hostel Complaint Management System
Project Overview
-----------------------


The Hostel Complaint Management System is a web-based application developed to streamline the complaint registration and resolution process within a hostel environment. The system enables students to submit complaints online and track their status, while administrators can manage and resolve complaints efficiently.
-------------------------


*Features*

Student registration and login
Complaint submission
Complaint status tracking
Admin login and dashboard
Complaint management and resolution
Secure database storage
Technologies Used
PHP
MySQL
HTML
CSS
JavaScript
Database

MySQL is used to store user information, complaint records, and complaint status updates.
----------------------------------------------------------
*How to Run the Project*

Install XAMPP or WAMP.
Copy the project folder to the htdocs directory.
Import the SQL database file into MySQL using phpMyAdmin.
Start Apache and MySQL services.
Open the project in a web browser using:
http://localhost/project-folder-name
